# 📝 Knowledge Base Application

A full-stack **Node.js** and **MongoDB** application featuring secure user authentication, authorization, and complete CRUD functionality for managing articles.

## 🚀 Features

- User Registration & Login
- Secure Password Hashing (bcrypt)
- Authentication & Authorization
- Create, Read, Update & Delete Articles
- Users can only edit/delete their own articles
- Protected routes for authenticated users
- MongoDB data storage

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB & Mongoose
- Passport.js
- Express Session
- bcrypt
- PUG

## ⚙️ Installation

```bash
git clone https://github.com/mudassar-web/md-knowledgebase-app.git
cd md-knowledgebase-app
npm install
npm start
```

## 🔐 Security

- Password hashing using bcrypt
- Session-based authentication
- Ownership-based authorization
- Protected CRUD operations
